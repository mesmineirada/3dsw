# Entregas

## Editor 3D no navegador
- [x] A aplicação permite criar e editar pequenas peças 3D diretamente no navegador.
- [x] A cena tem grade em milímetros, eixos de referência e câmera com órbita, zoom e deslocamento.

## Formas, seleção e transformações
- [x] O usuário pode criar cubo, cilindro, esfera, cone e prisma.
- [x] O usuário pode selecionar um ou mais objetos por clique, com indicação visual do item ativo.
- [x] O usuário pode mover, rotacionar e redimensionar objetos por controles visuais e campos numéricos.
- [x] O usuário pode editar dimensões exatas em milímetros, com leitura de largura, altura e profundidade.

## Modelagem e organização
- [x] O usuário pode duplicar, excluir, agrupar, desagrupar e espelhar objetos compatíveis.
- [x] A aplicação oferece união, subtração e interseção básicas entre sólidos selecionados.
- [x] A aplicação permite desfazer e refazer as principais operações.

## Impressão 3D
- [x] A aplicação valida o volume de trabalho de até 300 × 300 × 300 mm.
- [x] A aplicação exibe alertas visuais para objetos ou dimensões fora dos limites.
- [x] A aplicação verifica o modelo antes de gerar o arquivo final.
- [x] O usuário pode exportar o modelo final em STL para levar ao fatiador/impressora 3D.
